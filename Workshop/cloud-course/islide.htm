Fundamentals

What Is Cloud Computing?

Delivery of servers, storage, databases, and networking over the Internet — on demand, pay-as-you-go.

  • Rent instead of buying physical hardware
  • Scale resources up or down in minutes
  • Provider manages data centers, power, cooling
  • Analogy: Electricity grid vs. own power plant

Security

Security & IAM

User → Authentication → Authorization → Permission → Resource

IAM Components

  • Users, Groups, Roles
  • Policies (JSON permissions)
  • MFA — multi-factor auth
  • Least privilege principle

Best Practices ✓

  • Enable MFA everywhere
  • Use roles, not access keys
  • Never commit secrets to Git
  • Encrypt data at rest & in transit
